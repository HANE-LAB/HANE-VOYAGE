## 画面

| 画面 | 代表什么 |
|---|---|
| 最前面的御座船 | 火羽的船。船头是她和 Kobuta，衣装按日期换（2022、2023 年的 2 月 14 日） |
| 船头的篝火 | 她最近开播的频率：旺、燃、微、熄 |
| 羽毛形的船队 | 那一天在船、一直陪到今天的人。上船越早，离她越近 |
| 船的样子 | 舰长：一面纸帆的小船；提督：多一间船屋；总督：两层船屋，船尾一对旗 |
| 船灯 | 粉丝牌等级越高越亮 |
| 蓝帆的小船 | 无名之舰：只知道人数、不知道是谁的船，大多后来离开了 |
| 桅顶的光柱 | 陪伴满一个月、半年、一年；之后每多一年更高 |
| 名牌 | 昵称、「第几艘」、等级、陪伴天数 |
| 海中鸟居 | 每月一座。一月的更高，匾上写年份 |
| 鸟居的样子 | 当月平均人数排前 15% 的插一对火羽，后 35% 的是素木，其余朱漆；按月份换四季装扮 |
| 鸟居上的名字 | 陪伴每满一年，名字和「奉納」写在那个月的鸟居柱上；三年以上是金字 |
| 航迹 | 陪伴越久越长 |
| 星星 | 每颗代表 10 位粉丝 |
| 烟花 | 人数突破 100、1000、2000……或大涨的日子；有时炸成火羽或 Kobuta 的头像 |
| 左上角读数 | 那一天的大航海总数、陪伴至今、无名之舰、老舰长人数 |
| 底部时间轴 | 每天的人数（橙色陪伴至今，灰蓝无名之舰）、篝火和粉丝数；白点是核对过的数字 |

## 操作

| 操作 | 作用 |
|---|---|
| 点船、鼠标悬停 | 显示名牌；点了镜头跟过去，「回到船队」或 Esc 回来 |
| 寻舟 | 按昵称、UID 或编号（如 `#1234`）找船 |
| 喇叭 | 开关配乐，默认关，页面会记住 |
| 从 2021 年开始 | 从头播放 |
| 电影模式 | 去掉界面，从头放映 |
| 速度 | 0.5、1、2、4 倍 |
| 视角 | 回望、俯瞰、远望 |
| 画风 | 二次元、写实 |
| 动态 | 完整、减少（默认完整） |
| 逢潮缓行 | 人数大涨大跌的日子前后放慢 |
| 收起、展开 | 把底栏收到只剩播放键 |
| 拖动画面 | 转视角；滚轮或双指缩放 |
| 方向键 | 逐日移动，按住 Shift 一次 30 天 |
| 空格 | 播放、暂停 |
