# HANE Voyage · 火羽舰队

火羽ひのめ的大航海可视化。她的旗舰在最前面，船头站着她和 kobuta，舰长、提督、总督组成羽毛形的船队跟在后面，从 2021 年起航到今天；每个月船头前方升起一座海中鸟居，样子随那个月同行的人数和季节变化；天上的星星是粉丝数；人数跨过 100 / 1000 人或大涨的日子放烟花，有的炸成火羽或 kobuta 的头像；船头的篝火随她最近开播的频率明暗。

HANE 系列的第二个产品，第一个是动态与直播档案 [HANE](https://hane-lab.github.io/HANE/)（本机放在本项目旁边的 `../hane`）。

> 当前是原型：船还是占位模型，但数据是真实采集的，来源见[数据](docs/DATA.md)。

## 使用方式

- **直接打开**：运行 `npm install` 和 `npm run build` 后，用 Chrome 或 Edge 打开 `dist/index.html`。three.js 已打包在这个文件里，只有字体需要联网。
- **本地开发**：运行 `npm run dev`，打开 `http://127.0.0.1:8770/`。根目录的 `index.html` 是开发入口，不能直接双击打开。
- **桌面版与离线版**：发布后在公开仓库 Releases 的「offline」里下载：`HANE-Voyage-setup.exe` 是 Windows 安装版，`HANE-Voyage.exe` 免安装，`HANE-Voyage-offline.zip` 是网页离线版。
- **操作**：点一条船看它是谁，镜头会移过去（拖动转视角，点「回到船队」或按 Esc 回去）；右上角「寻舟」按名字或 UID 找船。「从 2021 年开始」播放整段航程，「电影模式」去掉界面、从头放映。设置按钮上写着现在的值：「速度」、「视角」（回望／俯瞰／远望）、「画风」（二次元／写实）、「动态」（完整／减少，默认完整）；「大事慢放」是开关，亮着就是开。点过按钮或按 Tab 到时间轴后，方向键逐日移动，按住 Shift 一次 30 天，空格播放和暂停。

## 数据说明

左上角的读数说的是播放到的那一天：「大航海」是那天船上的总人数，分成「陪伴至今」（那天在船、一直留到今天的人，再按等级分成舰长和提督·总督）和「后来离开」（那天在船、后来离开的人，画成无名之舰）。陪伴至今里还数出陪伴满一年、半年、一个月的老船长：他们的桅顶立着一道光柱，陪伴越久越高越亮，一年以上每年多一道升起的光环。陪伴天数用 B 站的数字，离开又回来的人算上以前的任期。各项的算法见[数据](docs/DATA.md#页面上的数字)。

陪伴一年以上的老舰长，名字一直挂在他们船上的光柱顶上；每满一年，名字还刻在那个月的鸟居柱上。其他人的名字平时不显示：鼠标停在一条船上、点一条船，或者用右上角的「寻舟」按名字或 UID 找船时，才显示那条船的昵称、等级和陪伴天数。头像和 UID 不显示；名单只保存 UID 的哈希，输入的 UID 只在本机算哈希比对。想让名字从页面上删掉，联系维护者。详见[数据](docs/DATA.md#名字与隐私)。
